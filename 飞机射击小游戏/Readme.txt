This is a practice-made airplane shooting game (endless mode), 
where players can operate their own aircraft to attack multiple enemy planes. 
The game consists of a cover with operation instructions, an in-game operation interface,
and a final battle-end screen. During combat, the health bar and real-time kill count 
are displayed in the top-left corner (the game ends when the player's aircraft is destroyed 5 times;
an enemy plane is successfully destroyed only after being hit twice). After each round, 
the score for that session is automatically displayed, providing a satisfying shooting experience. 
All textures used in this game were downloaded from the website https://opengameart.org/.
